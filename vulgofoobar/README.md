# Vulgofoobar

### Default

A minimal, stats-focused touchbar with system monitoring and media controls. The images used in this theme can be found in the [assets](assets/) folder.

![](vulgofoobar/default.png)

* Weather (open "Weather" app once press)
* CPU stats
* RAM stats (open the "Activity Monitor" app's memory tab once press.)
* Brightness down
* Brightness up
* Volume down
* Volume up
* Play
* Play next
* Date and time
* Battery status and remaining time

### Minimal foobar

A minimal bar with a styled nickname on the left and a few of my most-used buttons.

![](vulgofoobar/foobar.png)

* Stylized text
* Brightness down
* Brightness up
* Volume down
* Volume up
